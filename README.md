# 実践的SQL学習サイト Hugoプロジェクト

## 1. 概要

このリポジトリは、Hugoを使用して構築された「実践的SQL学習サイト」のソースコード一式です。
SQL初中級者を対象とした学習コンテンツと、サイトを生成するためのカスタムテーマ（* 別 repo で管理) を含んでいます。

## 2. 前提条件

このプロジェクトをローカル環境でビルド・プレビューするためには、以下のソフトウェアが必要です。
*   **Hugo:** `v0.100.0` 以上を推奨します。
    *   インストール方法: [Hugo公式サイト](https://gohugo.io/installation/) をご参照ください。

## 3. ディレクトリ構造の概要

-   `content/`: サイトの全学習コンテンツ（Markdownファイル）が格納されています。
-   `themes/sqldocs/`: このサイト専用のカスタムテーマです。レイアウト、CSS、ショートコードなどが含まれます。
-   `data/`: サイト内で使用される文言などを管理するデータファイル（YAML形式）です。
-   `hugo.toml`: Hugoプロジェクト全体の設定ファイルです。
-   `setup_sqlite.sql`: 演習用のサンプルデータベースを作成するためのSQLファイルです。

## 4. ローカルでの開発・プレビュー方法

1.  ターミナルを開き、このプロジェクトのルートディレクトリに移動します。
2.  以下のコマンドを実行します。

    ```bash
    hugo server
    ```
3.  ブラウザで `http://localhost:1313/` にアクセスすると、サイトのプレビューが表示されます。
    ファイルを編集・保存すると、ブラウザが自動的にリロードされ、変更が反映されます。

## 5. サイトの公開（ビルド）方法

サイトをWebサーバーにアップロードするための、公開用の静的ファイルを生成します。

1.  ターミナルを開き、このプロジェクトのルートディレクトリに移動します。
2.  以下のコマンドを実行します。

    ```bash
    hugo
    ```
3.  コマンドが完了すると、プロジェクトルートに `public/` ディレクトリが生成されます。
4.  この **`public/` ディレクトリの中身すべて**を、お使いのWebサーバーにアップロードすることで、サイトが公開されます。
