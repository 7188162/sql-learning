weight: 42
---
数値データの計算や丸め処理に使用します。

| 関数 | 説明 | 例 |
|:---|:---|:---|
| `ROUND(num, [digits])` | 四捨五入する。`digits`は小数点以下の桁数。 | `ROUND(123.456, 1)` -> `123.5` |
| `CEIL(num)` / `CEILING(num)` | 小数点以下を切り上げる。 | `CEIL(123.456)` -> `124` |
| `FLOOR(num)` | 小数点以下を切り捨てる。 | `FLOOR(123.456)` -> `123` |
| `ABS(num)` | 絶対値を返す。 | `ABS(-100)` -> `100` |
| `MOD(num1, num2)` | `num1`を`num2`で割った余りを返す。 | `MOD(10, 3)` -> `1` |
